MyCarrier Public API — curl reference
QA base URL : https://preprod-api.mycarrier.dev
PROD base URL: https://api.mycarriertms.com
Auth         : HTTP Basic (username:api_key) + X-Mc-Api-Key header

Replace <USERNAME>, <API_KEY>, <DATE>, <REF> with real values.
===============================================================================


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. GET SHIPPING LOCATIONS
   Code: mycarrier_action_sync_locations()
   Path: GET /api/v1/address/shipping-locations?skip=0&take=100
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

curl -X GET "https://preprod-api.mycarrier.dev/api/v1/address/shipping-locations?skip=0&take=100" \
  -u "<USERNAME>:<API_KEY>" \
  -H "X-Mc-Api-Key: <API_KEY>" \
  -H "Accept: application/json" \
  -H "User-Agent: Syncoria-Odoo/1.0"

3. RATE AND SAVE (picking flow — Button 2 / Select Rate)
   Code: mycarrier_action_select_rate()
   Path: POST /api/v1/quote/rate   action=RATE_AND_SAVE
